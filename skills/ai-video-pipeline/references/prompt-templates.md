# 提示词模板（Seedance 2.5）

这些模板是起点，不是咒语。每次都要根据镜头改素材编号、角色描述、动作和时间戳；不要把整段文学描写塞进去。

## 0. 通用后缀

```text
写实电影质感，真实光影与材质，35mm 胶片颗粒，自然肤色与皮肤肌理，毛孔和细纹可见，避免过度磨皮、蜡感、塑料感或 CG 感。画面稳定，人物身份、比例和空间关系一致。
```

## 1. 白模参考（单主角 + 场景）

```text
参考 @视频1 的运镜、动作路径、角色站位、景别变化、镜头顺序与节奏；白模只提供运动与机位骨架，不要参考它的灰色材质和几何外观。
将 @视频1 中的白色人偶映射为 @图片1 的角色：[年龄/性别/发型/服装/体型/气质]；场景使用 @图片2 的 [环境/光线/色温/空间材质]；[道具] 参考 @图片3。
【镜头】[景别]，[机位/运镜]，[焦段/景深]。
【动作】0-2s：[动作]；2-5s：[动作]。
【风格】[整体风格]，写实电影质感，真实皮肤肌理，自然光影。
【严格排除】不保留白模材质、轨迹线、坐标轴、网格线或相机锥体；无字幕、无水印、无文字、无logo；手部不入画；不出现多指、少指、畸形手、扭曲肢体、面部身份漂移。
```

## 2. 白模参考（多主角）

```text
参考 @视频1 的运镜、走位、景别与节奏；白模只提供运动骨架。
人物映射：@图片1 是角色 A（[描述]），@图片2 是角色 B（[描述]）；@视频1 中左侧的白色人偶对应 A，右侧对应 B。
场景参考 @图片3（[环境/光线]）。
保持 A 和 B 的身份、服装、体型、站位关系；同一画面中每个角色只出现一次，不要生成双胞胎、分身或角色互换。
【镜头】...
【动作】...
【严格排除】...
```

> 多主体 1–5 个最稳；超过 5 个会明显掉稳定性。复杂肢体接触拆成单人镜头。

## 3. 首帧 / 首尾帧

```text
从首帧自然过渡到尾帧，镜头 [推/拉/环绕/固定]，保持人物身份、服装、发型、体型和场景光线一致。
【动作】[首帧到中间到尾帧的动作变化]。
【风格】...
【严格排除】...
```

参数：`mode=first_last_frame`，`first_frame`/`last_frame`，`ratio=adaptive`，`duration` 4–30 或 -1。

## 4. 编辑（只改局部）

```text
仅编辑 @视频1 中 [时间区间] 的 [对象/区域]：[A -> B]。
其余内容保持不变：人物身份、动作、机位、构图、光线、背景、服装（除指定修改外）、音频。
【严格排除】不要重绘整条视频；不要改变未指定的区域；不要字幕/水印。
```

参数：`mode=edit`，`omni_reference_task_type=edit`，`reference_videos=[原片 URL]`，`ratio=adaptive`，`duration=-1`，`output_format=mov`。

## 5. 延长（续写）

```text
向后延长 @视频1 [N] 秒：[新动作/新场景/新台词]。
保持人物、服装、场景、光线、镜头风格与 @视频1 一致；动作和音频无缝衔接。
【镜头】...
【严格排除】...
```

参数：`mode=extend`，`omni_reference_task_type=extend`，`reference_videos=[原片 URL]`，`ratio=adaptive`，`duration=4-30`，`output_format=mov`。

## 6. 对白 / 口型

```text
人物 [A] 对镜头说：“[台词]”，语气 [情绪]，口型与台词逐字同步。
只生成这一句台词；不要增加对白、旁白或字幕；环境音 [描述]，无 BGM。
```

参数：`generate_audio=true`。台词放在双引号里；不要在台词后堆表情/动作描述，容易诱发字幕。

## 7. 音频参考

```text
参考 @音频1 的 [音色/节奏/音乐风格]；人物 @图片1 使用该音色说：“[台词]”。
只保留人声与环境音，不要背景音乐。
```

`Seedance 2.5` 可单独输入音频；`2.0` 不能单独用音频，至少配一张图/一个视频。

## 8. 镜头语言词典

- 景别：大远景 / 远景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 大特写
- 运镜：推 / 拉 / 摇 / 移 / 跟 / 环绕 / 升降 / 俯冲 / 手持 / 斯坦尼康 / 固定
- 机位：平视 / 低角度 / 俯视 / 过肩 / 第一人称 / 荷兰角
- 转场：硬切 / 叠化 / 甩镜 / 遮挡转场 / 匹配剪辑
- 光：黄金时刻 / 冷蓝暮色 / 暖色台灯 / 侧逆光 / 柔光 / 硬光 / 实用光源

## 9. 负向控制

官方 API 没有 `negative_prompt` 字段；插件会把它并入正向提示词末尾的“严格排除”。负向词只写真正必须排除的：

- 字幕、水印、文字、logo
- 多指、少指、畸形手、扭曲肢体
- 面部身份漂移、换脸、双胞胎/分身
- 白模材质、轨迹线、坐标轴、网格线、相机锥体
- 过度磨皮、蜡感、塑料感

不要把所有形容词的反义词都列一遍；负面词太多会分散模型注意力。

## 10. 真人合规

Seedance 2.5/2.0 会拦截直接上传的真人脸参考图/视频。可选：

1. 用 AI 生成的写实虚拟人像（推荐）。
2. 用平台预置数字人。
3. 用已授权并入库的 `asset://` 素材（需要方舟素材库/高级创作权益包）。

3D/插画/风格化角色不受真人脸限制。不要尝试用真人照片绕过审核；会失败，也可能带来合规风险。
