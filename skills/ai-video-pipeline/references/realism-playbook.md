# 超写实修复手册（Realism Playbook）

> 这一页是对 AIsp《靶场校准》那轮"没做出超写实"的完整复盘：
> 用了什么证据、根因在哪、改了哪几层、怎么验证。
> 结论先说：**问题不在提示词不够"重"，而在白模参考里没有可写实化的信息。**

## 1. 调查证据

### 1.3 1:1 目视（这是关键，缩略图看不出来）

- **盔壳**：一整片均匀柔光，没有掉漆、没有导轨滑痕、没有指纹；边缘过于干净。
- **护目镜**：镜片上的"灯管反光"是**画上去的白色短杠**，与画面里的真实灯位不对应。
- **面罩**：织纹是均匀的平铺图案，没有厚度、没有起球、边缘没有卷边。
- **手套**：一整块无指缝的皮面，没有缝线、没有掌心油光、没有磨损。
- **手枪**：套筒/照门/扳机护圈融成一团黑色软块，没有机加工棱线、没有油光、没有积垢。
- **纸靶**：纯色块 + 印刷圆环，没有纸纤维、没有毛边。

### 1.4 第二个案例：peak-photoreal（超写实黑骑士）——参考是几何真源

| 项 | 实测 |
| --- | --- |
| 参考模型 | `peak_photoreal.blend`：**5,883 个面 / 122 个对象**，最大单体是 512 面的月亮，**零修改器** |
| 白模形态 | 圆锥 + 球 + 面片组成的低模崖顶；岩石是低多边形块 |
| 生成 | 3 镜 × (480p 样片 + 1080p 交付) = 6 次，全部 reference + 2 张锚图 |
| 成片 | 岩石是**大块面**、地面是**平板**、斗篷是**锯齿面片**、魔物是**低模块状**——参考的拓扑被完整继承 |
| 提示词 | 甚至写了"不是圆锥体、不是圆柱、不是低多边形几何体"——**完全无效** |

结论：在 reference 模式下，**参考视频的几何就是输出的几何**。文字否定不了拓扑，
材质代理也改不了拓扑。5,883 面的场景 × 6 次生成 = 90.9 成本指数，全部买到了"低模打光"。

所以 LOD 必须作为生成前的硬门：

| 景别 | 参考模型评估后多边形数下限 |
| --- | --- |
| 远景 / 全景 (WS/LS/EWS) | 20,000 |
| 中景 / 中近景 (MS/MCU) | 80,000 |
| 特写 / 大特写 (CU/ECU) | 200,000 |
| POV / 过肩 (POV/OTS) | 100,000–150,000 |

不达标 → 先建模（细分/置换/布料/倒角/雕塑），不要涂色、不要改提示词。
风格化项目（动漫/赛璐璐）在契约里写 `"look": {"style": "stylized"}`，这个门自动关闭。

## 2. 根因链

```
白模是「平涂灰块 + 纯白背景」
   ↓  没有任何明暗渐变、没有材质分区、没有微观细节
模型只能从剪影猜形体
   ↓  "光滑简单体块"是它最安全的解释
输出沿用了白模的形体语言 → 均匀高光 + 干净边缘 + 画上去的反射
   ↓  prompt 里的"超写实"没有可执行的落点
没有摄影机/镜头/材质/磨损清单，模型不知道"写实"具体指什么
   ↓  验收是看 480p 缩略图
平滑的 CG 在缩略图上反而"干净精致" → 被判通过
```

一句话：**参考视频里没有的东西，不能指望形容词补上。**

## 3. 修法（已落地）

### 3.1 材质代理（materials proxy）——最重要的一层

平涂白模 → 「材质分区 + STUDIO 光照 + 阴影 + 空腔 + 高光 + 中性灰背景」：

```bash
# 新镜头：直接用代理渲染（一次出一支参考视频）
node .dsh/skills/ai-video-pipeline/scripts/render-shot.mjs \
  --spec projects/p/shot_01.json --out projects/p/renders/shot_01 --proxy

# 已有 .blend：不改工程，直接渲代理参考视频（可 A/B 对照）
node .dsh/skills/ai-video-pipeline/scripts/proxy-render.mjs \
  --blend projects/p/blockout/scene.blend --camera shot_01_cam --frames 1-120 \
  --out projects/p/blockout/proxy/shot_01 --style proxy

# 材质分类不对时（例如手其实戴着手套）用 --map 覆盖
node .dsh/skills/ai-video-pipeline/scripts/proxy-render.mjs … --map "hand=gear"
```

实测（range-test shot_03 同一帧）：平涂版是一块灰色剪影，代理版能看出
头/盔/镜/面罩/护肩/前臂/手/手套/枪的**分区与明暗**，模型终于有东西可写实化。

要点：

- **平滑着色**必须开，否则低模球体的每一圈多边形会被 cavity 描出来，
  参考视频变成"线框低模"，模型照抄低模。
- **枪口焰/粉尘**（fx）默认隐藏：白模里它们是一个球，会被模型当成实体。
  闪光时机交给 `cues`。
- 代理颜色是**约定**不是美术：它告诉模型"这块是织物、那块是金属"。
  分类错了要改（`--map`），不要放任。
- 背景用中性灰（0.23），不要纯白——纯白会诱导模型把环境画成过曝。

### 3.1.1 还有第二根轴：形体可读性

材质代理补的是**材质与光照**，补不了**形体**。这一轮白模里：

- 头盔是一个球 → 成片头盔就是个圆壳；
- 手枪是「slide + frame + grip + trigger_guard」四个方块 → 成片是一团黑色软块；
- 手是球、手套没有指槽 → 成片是无缝的连指块。

规则：**白模的形体要"读得出装备"**——头盔用壳形（不是球）、枪要有套筒/握把/准星分件、
手套要有拇指与指槽、护目镜要贴合面部曲率。做不到全部，至少把**剪影上看得见**的分件做出来。

这一条的成本仍然为零（Blender 里加几个倒角/分件），但它决定了模型能画到什么精度。
需要更强的形体控制时，用 `blender-modeling` 技能的 `shapesolve`（按参考图拟合轮廓）
和 `asm_*`（装配体检）把白模做准。

### 3.2 契约 `look` 段：把"超写实"拆成可执行清单

```json
"look": {
  "camera": "ARRI ALEXA Mini LF + 35mm 定焦，T1.8，1/48s，ISO 800，3200K 实用顶光 + 5600K 侧补",
  "character_materials": ["盔壳：磨砂尼龙，边缘掉漆露底漆", "护目镜：镀膜聚碳酸酯，细划痕与指纹油污", "…"],
  "scene_materials": ["混凝土地面：骨料颗粒、轮胎印、积灰", "…"],
  "negative": ["CG 渲染感", "游戏引擎画面", "塑料反光", "画上去的假反射"]
}
```

`prep-shot.mjs` 会把它拼成【摄影与材质】段，并把这些排除项并入 `negative_prompt`。
没有 `look` 段时脚本会告警：超写实只剩形容词。

### 3.3 验收：`qa-realism.mjs`

```bash
node .dsh/skills/ai-video-pipeline/scripts/qa-realism.mjs --project projects/p
```

- **强制 1:1 裁切**（不缩放），逐张看——缩略图是本轮"误判通过"的直接原因。
- 三个数字：`detail`（纹理能量）、`grain`（高频残差）、`range`（动态范围）。
- 阈值按**单个作物**设 `minDetail`（纸这种本来就光滑的材质单独放宽），
  不要全局放水。
- `grain` 在 H.264/HEVC 之后会被压平，只作提示，不参与硬判定。

## 4. 超写实检查清单（付费前 + 验收时）

付费前：

- [ ] 参考视频是**材质代理**，不是平涂灰模
- [ ] 代理里主体分区正确（织物/装备/金属/皮肤不会混）
- [ ] 契约 `look.camera` 写了机身/焦段/光圈/快门/ISO/色温
- [ ] `look.character_materials` 每件装备都有"材质 + 使用痕迹"
- [ ] `look.negative` 包含反 CG 项（渲染感、塑料反光、画上去的假反射）
- [ ] 首帧锚图是**照片级**的（不能拿未验收的生成帧当锚）

验收时（1:1，不许看缩略图）：

- [ ] 皮肤/织物有微观纹理与毛孔/织纹，不是均匀平滑面
- [ ] 金属有机加工棱线与油光，不是融合软块
- [ ] 镜片反射对应画面里的真实光源，不是画上去的白条
- [ ] 边缘/紧固件有掉漆、磨损、积灰
- [ ] 有摄影噪点/颗粒（`grain` ≥ 0.0005 提示线）
- [ ] `qa-realism` 无硬失败

## 5. 反模式

| 反模式 | 后果 |
| --- | --- |
| 用平涂灰模当参考视频 | 模型照抄"光滑简单体块" |
| 只在 prompt 里堆"超写实/8K/电影感" | 没有可执行落点，等于没说 |
| 拿成片帧当定妆锚 | 把 CG 感固化成身份标准 |
| 看 480p 缩略图验收 | 平滑 CG 反而"看起来干净"，必错判 |
| 给每件装备只写"战术头盔" | 模型只能画个大概的壳 |
| 用"不要塑料感"当唯一约束 | 负向词没有正向替代，模型仍会选最省事的解 |
